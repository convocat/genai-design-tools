# Handover notes

One file per session handover. Named `YYYY-MM-DD-short-title.md`. Generated by `/handover`.

## What lives here

Each handover note has two sections (per Maaike's [handover clarity rule](https://www.maaike.ai/backlog)):

1. **Session sign-off** — what was done, what was decided, what was left open. This closes the session that just ended.
2. **Next session brief** — what the next session picks up, what context to load, what to do first. Includes a paste-ready opening message.

`/handover` also prepends a corresponding entry to [../backlog.md](../backlog.md) under 🔵 / 🟡 / 🟠 depending on status.

## Naming

`YYYY-MM-DD-short-title.md` — e.g. `2026-05-27-project-scaffolding.md`. If multiple handovers happen on the same day, append `-2`, `-3`.

## Conventions

- Date format: YYYY-MM-DD.
- No em-dashes.
- Sign-off and next-session brief are distinct sections. Never blur the two.
- Reference SPEC.md by section number when relevant.
- If a decision landed during the session, link to the decisions.md ADR.
